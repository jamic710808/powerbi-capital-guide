# storyboard — 《有個口袋在冒汗》

- 風格：A 扁平插畫＋MG 動效（見 `style-choice.md`）；1920×1080、30 fps、橫屏；總長 6485 幀 / 216.17 s（3:36.2）。
- 技術：Canvas 2D，所有畫面由 `renderFrame(frame)` 純函數決定；固定隨機種子；場景為 `scenes-a/b/c.js` 內的 `SCN[sceneId](c, K)`。
- 色板：ink `#0f2b3d`、teal `#14a3b3`、orange `#ff8a3d`、奶油色背景。字型：Noto Sans TC（本地）。
- 聲音：旁白 Gemini TTS Kore（溫和女聲，單一聲線，老闆只以手機對話框出現）；配樂為程式合成（marimba / pizzicato / pad，BPM 108，旁白時自動閃避）；音效對時於旁白關鍵字。
