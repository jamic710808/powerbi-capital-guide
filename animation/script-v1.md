# script（v1）— 《有個口袋在冒汗》
副標：PowerBI資金分析報告，看全局，也看每個口袋

## 一句話
集團老闆一通電話問「帳上有錢嗎」，財務主管阿帳答「有，約四點三億——不過有個口袋，十月十五日會先見底」。這一天，阿帳帶著報告走完六站，從「總量夠」一路查到「哪個口袋、哪一天、缺多少、能不能先向家人調、避險會不會有副作用」，傍晚終於知道該去敲哪一扇門。

> 旁白全程只叫「阿帳」，**不使用人稱代詞**；角色造型與性別在製作階段於已選風格內定案。

## 敘事形式
能力介紹型動畫：**任務（一個太籠統的問題：「有沒有錢？」）→ 能力如何改變過程（六張內頁，一層層定位）→ 實際價值（知道該找誰談、先做什麼）**。骨架沿用報告的使用順序（文章：先看全局缺口，再逐項定位原因，最後落到法人、渠道或合同明細）。

## 世界觀與角色（外觀依已選風格，製作時定案）
- **阿帳**：集團財務主管，溫暖、略帶焦慮、嘴上幽默。馬克杯、便利貼、日曆三個小道具承載情緒。（**沿用前作《錢，怎麼還沒回家？》的阿帳**，成為同一系列；要不要沿用，見文末「待你審核」。）
- **銅板小隊**：錢本身。圓圓的小銅板，住在口袋裡。（沿用前作。）
- **六個口袋**：六家法人的化身，各有名牌與表情——總部、華東、華北、華南、跨境運營、**香港貿易**。香港貿易的口袋常冒汗，是全片的笑點與情感線索。
- **老闆**：只以手機對話框出現（單一聲音規則），從不露面。
- **地圖／看板**：Power BI 報告的化身，片中標「示意」。（沿用前作的「地圖」概念，這次走六站。）

## 幽默準則
1. 笑點來自財務日常的真實小痛，不嘲笑老闆、客戶或同仁。
2. 每個笑點之後立刻接一條**真實資訊**；幽默不蓋過數字。
3. 數字與限定條件（假設、候選安排、授信不是現金）一律保留。
4. 全片的反覆笑點只有一個：**香港貿易的口袋**（冒汗 → 忙 → 被點名 → 被補上針線），其餘笑點各用一次，不重複。
